# MEDS5420 Final Project  
## Comparative RNA-seq analysis using STAR and a lab pipeline for human transcriptome profiling and investigation of unexpected expression patterns

This repository contains the final project for MEDS5420.

## Project Overview
This project analyzes RNA-seq data to evaluate the effectiveness of XBP1 knockout using:
- STAR-based alignment
- FeatureCounts quantification
- Differential expression analysis
- IGV visualization
- RT-PCR validation

## Repository Structure

- Final_Project.Rmd: Full analysis workflow in R Markdown  
- Final_Project.html: Rendered report with results and figures  

- figures/: All figures generated in the analysis  
- counts/: Gene-level count data from FeatureCounts  
- data/: Processed datasets including TPM matrix and differential expression results  
- scripts/: Key pipeline scripts for alignment and quantification  

- Final_Project_DE_results.xlsx: Differential expression results  
- Final_Project_TPM_expression_matrix.xlsx: TPM expression data  

## Note
Only key scripts and results are included in the R Markdown file. The complete pipeline will be provided separately.
